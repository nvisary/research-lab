## Хелпер (`_lab.py`)

```python
import sys; sys.path.insert(0, ".")   # cwd = notebooks/pairs
from _lab import *

list_symbols()                              # все символы на диске
coverage("AVAXUSDT")                        # ('2024-01','2026-04', 28)

# выровненная пара (inner-join по общему индексу), колонки a / b
px = load_pair("ETHUSDT", "BTCUSDT", "2024-01-01", "2024-07-01", tf="1h")

s   = log_spread(px)                         # log(a) - beta*log(b), beta по OLS
z   = zscore(s, window=24*7)                 # rolling causal z-score
hl  = half_life(s)                           # half-life возврата к среднему, в барах
show("eth_btc_spread")
```

`_lab.py` — обёртка над `datafeed.loader` + pair-хелперы. Данные — Bybit perp 1m
parquet; `tf` ресемплит на лету (`1h`, `4h`, `1d`, ...). Для парного анализа
по умолчанию берём `1h`/`4h`, 1m — только когда реально нужна гранулярность.

## ⚠️ No-lookahead для пар (читать перед первым тестом)

- **β и mean/std спреда оценивай на TRAIN, применяй вперёд.** `log_spread()` и
  `zscore()` без `window` используют весь переданный кусок — это только для
  глаз. Для теста: фитим на train-окне, торгуем на следующем.
- **Rolling z (`window=...`) — каузальный**, на каждом баре только прошлое.
- **Коинтеграция тоже может развалиться OOS.** Пара, коинтегрированная в 2024,
  не обязана быть такой в 2025 — проверяй на другом периоде.
- **Costs.** Парная сделка = 2 ноги → удвоенный round-trip (~0.2–0.4% alt-perp)
  плюс funding на обе ноги. Edge ниже этого — не edge.

## Журнал исследования (держать актуальным)

- `00_smoke` — проверка петли: загрузка выровненной пары, log-спред, каузальный
  rolling z-score, `show()`. Пара ETH/BTC как sanity-check, без претензии на edge.
- `01_meanrev_check` — **precondition ПРОВАЛЕН для статичной пары ETH/BTC.**
  β фитим на train (H1-2024), применяем вперёд. Даже на train ADF p=0.11
  (не отвергаем random walk), half-life 13.5 дн. На OOS (H2-2024) спред
  **дрейфует вниз на −3.8 train-σ** и не возвращается — ETH структурно
  проиграл BTC. **Урок: «со-движутся на глаз» ≠ коинтегрированы; соотношение
  majors свободно дрейфует на горизонте месяцев.** Ставить на возврат к
  *фиксированному* среднему = шортить тренд. Следующий шаг — rolling-z
  (возврат к *недавнему* среднему, адаптируется к дрейфу).
- `02_coint_scan` — **stage 1 (селекция) честно: скан 165 символов, 13530 пар,
  Engle-Granger на train (H1-24) → ре-тест на OOS (H2-24).** train p<0.05:
  1886 пар (13.9% vs 5% случайных = 2.79×). **Выжили на OOS: 236 = 12.5%
  (vs 5% = 2.50×).** Вывод: отбор выше шума, но **коинтеграция быстро распадается
  — 87.5% train-пар ломаются за полгода**; OOS-ре-тест обязателен. Флаги:
  (1) стейблы (USDC beta≈0) дают мусорную «коинтеграцию» — исключать;
  (2) выжившие = мелкие неликвидные алты (GMT/KAVA/WOO/SC/SCRT…) → костовый
  риск для 2 ног. **Селекция-по-OOS сама = lookahead**: торговать выживших надо
  на 3-м периоде (2025+).
- `03_signal_one_pair` — **stage 2 механика на ОДНОЙ паре (GMT/KAVA), торг на
  2025 (нетронутый период).** Rolling-beta + rolling-z (W=270 бар/45дн, каузально),
  β заморожена на входе, entry|z|>2 / exit|z|<0.5 / stop|z|>3.5, косты на 2 ноги.
  Результат = **не-результат**: n=6, net +0.08 но **держится на 1 сделке**,
  медиана −0.08, win 33%, m/std 0.05, **maxDD −44%**. Движок валидирован
  (косты монотонны 0→30bps, входы/выходы корректны). **Уроки:** (1) одна пара =
  огромный идиосинкратический риск; β-хедж убирает общий рыночный фактор, но
  спред-специфичный тренд остаётся → «нейтральность» не спасает от соло-дродауна;
  весь смысл pairs — диверсификация по многим парам. (2) сделки жили 12–37 дн при
  HL~5дн → коинтеграция 2024 подраспалась к 2025. Следующий шаг — nb04:
  **портфель** по пулу выживших (много пар, кап капитала, baseline).
- `04_walkforward_portfolio` — **честный walk-forward (нет survivorship/selection
  lookahead): помесячный переотбор, formation=6мес trailing → торг 1мес вперёд,
  β/mean/std заморожены с formation, 30 пар равновес, 137 алтов, 2024-07..2026-04.**
  **РЕЗУЛЬТАТ: ТЕРЯЕТ** — total −6.8 (лог), Sharpe −8.8, 21/22 мес красные;
  random-timing baseline теряет ещё больше (−7.3) → проблема НЕ в тайминге.
  Persistence пар = 22% (коинтеграция протухает за месяц). **Механизм убытка
  (диагностирован):** frozen formation mean/std → z свежеотобранной пары в след.
  месяце улетает на +10..15σ и застревает (спред детонирует, не возвращается) →
  жёсткий стоп даёт цикл стоп→перезаход→стоп ~90 форс-стопов/пару/мес, каждый
  платит за 2 ноги = costs-мясорубка. **Вывод: наивный Engle-Granger + frozen-z +
  hard-stop на крипто-алтах НЕ торгуется.** Фиксы для nb05: (1) rolling causal z
  вместо frozen mean (recalibrates, не пришпиливает z к 13); (2) убрать
  stop→reenter churn (time-exit / no reenter в той же экскурсии).
